# 三打哈（三打一）

湘西扑克游戏**三打哈（三打一）**的 Godot 单机版工程。

- **项目规范**：[AGENTS.md](./AGENTS.md)（架构/编码/UI/测试/推送约定，随实现同步更新）
- 规则唯一依据：[三打哈规则.md](./三打哈规则.md)（含附录 A 完整推演、附录 B 单轮决策流程）
- 技术决策与里程碑：[三打哈-Godot工程计划.md](./三打哈-Godot工程计划.md)

## 技术栈

| 项目 | 设定 |
|---|---|
| 引擎 | Godot 4.7（gl_compatibility 渲染，兼容桌面/移动/Web） |
| 语言 | GDScript |
| 规则引擎 | `core/` 纯逻辑类（不依赖场景节点），单机与联机服务端共用 |

## 目录结构

```
core/     规则引擎（M1）+ 对局引擎与 AI（M2）：
          card / trump / combo / follow_rule / trick / game（状态机）/ ai_policy（贪心策略）
tests/    轻量测试框架 + 58 项用例（含附录 A 推演、抠底剧本、30 局自动对局不变量）+ UI 冒烟
scenes/   场景（main_menu 主菜单、game_table 牌桌）
scripts/  场景脚本（game_table 控制器、card_widget 程序化卡牌）
```

## 运行

```bash
# 编辑器安装位置：S:\Program\Godot\（环境变量 GODOT_PATH 已指向主程序）
# 用 Godot 4.7+ 打开本目录即可运行（主场景：主菜单 → 开始对局）

# 规则引擎 + 对局引擎测试（全部通过退出码 0）
Godot --headless --path . -s tests/run_tests.gd

# UI 冒烟测试（headless 自动打完一局，约 1 分钟）
Godot --headless --path . -s tests/smoke_ui.gd
```

## 玩法（M2 单机对局）

1 人（甲，下方）对 3 电脑（乙/丙/丁）。流程：叫分拍卖（抓牌庄家底叫 130，加叫 +5 倍数封顶 200）→
出牌庄家叫主（主花色 + 常主 R）→ 翻底扣底 8 张 → 逐轮出牌（跟/杀/垫由引擎校验，非法出牌会提示原因）→
末轮抠底 → 按 205 分线分级结算（基底分 B=1）。多局连续进行，庄位按规则 4 轮换，累计收益显示在顶栏。

主菜单的「规则引擎自检」按钮会在进程内运行同一套测试并显示结果。

## 里程碑

- **M1 规则引擎 ✅**：牌与牌型、邻接链、跟牌/杀/垫判定、一轮结算、并列规则
- **M2 单机对局 ✅**：完整一局（拍卖/叫主/翻底扣底/逐轮出牌/抠底/分级收益/庄位轮换）+ 贪心 AI + 牌桌 UI
- M3 AI 对手与胜率分析（蒙特卡洛评估、候选出牌打分）；M4 联机对战；M5 部署上线
