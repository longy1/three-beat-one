# 三打哈（三打一）

湘西扑克游戏**三打哈（三打一）**的 Godot 单机版工程。

- 规则唯一依据：[三打哈规则.md](./三打哈规则.md)（含附录 A 完整推演、附录 B 单轮决策流程）
- 技术决策与里程碑：[三打哈-Godot工程计划.md](./三打哈-Godot工程计划.md)

## 技术栈

| 项目 | 设定 |
|---|---|
| 引擎 | Godot 4.7（gl_compatibility 渲染，兼容桌面/移动/Web） |
| 语言 | GDScript |
| 规则引擎 | `core/` 纯逻辑类（不依赖场景节点），单机与联机服务端共用 |

## 目录结构

```
core/     规则引擎（M1）：card / trump / combo / follow_rule / trick
tests/    轻量测试框架 + 规则用例（含附录 A 推演验收）
scenes/   场景（main_menu 主菜单、game_table 牌桌桩——M2）
scripts/  场景脚本
```

## 运行

```bash
# 编辑器安装位置：S:\Program\Godot\（环境变量 GODOT_PATH 已指向主程序）
# 用 Godot 4.7+ 打开本目录即可运行（主场景：主菜单）

# 规则引擎测试（M1 验收命令，全部通过退出码 0）
Godot --headless --path . -s tests/run_tests.gd
```

主菜单的「规则引擎自检」按钮会在进程内运行同一套测试并显示结果。

## 里程碑

- **M1 规则引擎**（进行中）：牌与牌型、邻接链、跟牌/杀/垫判定、一轮结算、并列规则
- M2 单机对局：拍卖、叫主、翻底/扣底、逐轮出牌、末轮抠底、分级与收益
- M3 AI 对手与胜率分析；M4 联机对战；M5 部署上线
